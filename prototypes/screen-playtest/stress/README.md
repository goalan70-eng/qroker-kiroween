# 최신 격자 배열의 합성 스트레스 검증

2026-11-21에 Codex가 `aa0f384`의 화면 검증 판독기로 시험했다. 30 mm 표시 크기와 조커 배치에서 마지막 중앙 관측을 추가한 배열을 직전 두 관측의 격자 배열과 비교했다. 두 배열에 같은 카드 배치, 투시 변환, 조명, 노이즈와 난수 시드 `26112052`를 사용했다.

| 합성 조건 | 직전 배열 | 최신 배열 |
|---|---:|---:|
| 네 장의 카드 ID와 합계 일치 | 1,198/1,394 | 1,204/1,394 |
| 60° 저조도와 부분 반사 | 24/34 | 30/34 |
| 60° 저조도와 흔들림 | 23/34 | 23/34 |
| 45° 강한 그림자 | 0/34 | 0/34 |

| 강한 흔들림 | 0/34 | 0/34 |
| 카드가 빠지거나 가려진 입력의 판독 거부 | 96/96 | 96/96 |

배열당 1,490건 중 틀린 카드 식별은 0건이었다. 최신 배열에서 새로 성공한 6건은 모두 60° 저조도에서 부분 반사가 생긴 경우였다. 이전에 정확히 읽히던 장면에서 새 판독 누락은 없었다.

웹게임 캡처를 판독한 결과로 추측 확정 로직도 검증했다. 카드 제거, 합계가 같은 다른 조합, 합계가 다른 조합, 확정 프레임 누락 뒤 원래 조합 복귀 상황에서는 오래된 제출이 저장되지 않았다. 새로 확정한 정상 제출은 채점됐으며 기록 파일에서 점수를 복원할 수 있었다.

이 결과의 범위는 합성 프레임과 JVM의 채점·프레임 매칭 로직이다. 실물 카메라·인쇄 카드 시험과 Android UI의 반응 시간 측정은 별도로 진행한다.

## 재현

상위 README의 Android 빌드로 최신 판독기의 JVM 클래스 디렉터리를 준비한다. 웹 빌드 후 브라우저 시험을 일반 모드와 코드 분리 모드에서 각각 실행한다.

```powershell
node ./verify-web.cjs
node ./verify-web.cjs --isolate-marker
```

직전 격자 배열 `grid-extension`과 최신 `center-grid`의 로컬 폴더에는 각각 `frames/manifest.tsv` 및 렌더링된 PNG가 필요하다. `-PriorClasses`에는 직전 배열의 Android 판독기를 컴파일한 클래스 디렉터리 `grid-extension/classes`를 지정한다.

```powershell
./stress/run.ps1 -PriorDeck $priorDeck -PriorClasses $priorClasses -CurrentDeck $currentDeck
```

`evidence/stress/`에 배열별 상세 판독, 비교표 `comparison.tsv`, 결과가 바뀐 사례 `changed-cases.tsv`, 채점 로그 `scoring.txt`가 기록된다. 로컬 도안·스크린샷·촬영 입력은 재현용 자료로 별도 보관한다.
