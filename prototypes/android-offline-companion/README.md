# QRoker 오프라인 점수 기록

Android 8.0 이상에서 실행하는 개인용 시제품이다. 후면 카메라가 기존 30 mm Composite Code의 카드 네 장을 읽으면 예측 입력을 연다. 예측을 확정하면 카드 숫자의 실제 합계와 점수를 표시하고 누적한다.

## 사용

1. `dist/QRoker-Offline.apk`를 Android 휴대전화에 복사해 설치한다. 앱을 열고 카메라 권한을 허용한다.
2. 기존 30 mm 인쇄안의 카드 네 장을 둥근 모서리끼리 맞닿게 배치한다. 카메라 미리보기 안에 결합 마커의 테두리 전체를 넣는다.
3. `N번째 추측`에 4~52의 정수를 입력하고 `확정`을 누른다. 인쇄 샘플의 5♥, 9♦, J♣, 2♠ 조합은 정답이 27이다.
4. 총점과 각 추측 결과는 앱을 종료했다 다시 열어도 남는다. 게임이 끝나면 `기록 삭제`에서 확인을 눌러 비운다. 앱의 데이터나 앱 자체를 삭제하는 경우 기록도 함께 지워진다.

오차 0~5의 점수는 순서대로 10, 5, 4, 3, 2, 1점이며 오차 6 이상은 0점이다. 같은 카드 네 장은 배치 순서가 달라도 한 번만 채점한다. 카드가 빠진 프레임에서는 실시간 판독과 예측 입력을 닫는다. 이미 확정한 점수는 개인 기록에 남는다.

## 구현과 재빌드

- Codex가 기존 30 mm 시제품의 판독 절차를 Java로 옮기고 Android 카메라, 채점, 기기 내부 파일 저장을 연결했다.
- APK에는 인식에 쓰는 좌표와 52장 코드북만 포함한다. 카메라 프레임은 메모리에서 처리하고 저장 파일에는 카드 조합 키, 예측, 정답만 기록한다. 카메라가 앱이 요청하는 유일한 권한이다.
- Android SDK Platform 36.1, Build Tools 36.1.0, JDK 21, Python 3이 준비된 Windows에서 이 폴더의 `build.ps1 -Source <로컬 자료 폴더>`를 실행한다. SDK와 JDK 위치는 `-Sdk`, `-Jdk`로 지정할 수 있다.
- `-Source` 폴더에는 `joker-uniform-bars-30mm-layout.json`, `uniform-bars-retest-input.json`, `small-marker-audit/live-full.png`, `small-marker-audit/live-missing.png`가 필요하다. 이 자료와 생성 APK·서명 키는 로컬 보관 대상이다.
- 재빌드 APK로 기존 설치를 업데이트하려면 첫 빌드에서 생성한 로컬 서명 키 `build/local-prototype.p12`를 사용한다. 이 키는 시제품용이다.
- 빌드는 합성 프레임 및 채점 회귀 테스트, APK 서명 검증, APK 권한 목록 확인을 포함한다.

## 검증 기준

60° 저조도 합성 프레임의 기준 정답은 27이다. 회귀 테스트는 원본과 분기별 90° 회전, 제한 범위 밝기, 같은 입력에서 한 장이 빠졌을 때의 판독, 점수 저장·재로딩·삭제를 검사한다. 실제 인쇄물과 휴대전화 기종별 인식률, 판독 지연은 별도 실물 시험 항목이다.

2026-11-20 검증에서 JVM 회귀 검사 19개가 통과했다. 비행기 모드에서 Wi-Fi를 끈 Android API 36 에뮬레이터로 합성 장면을 후면 카메라에 입력했다. 예측 전 정답이 숨겨지고, 27을 제출하면 정답 27과 10점이 기록되며, 프로세스를 강제 종료하고 다시 실행했을 때 총점과 기록이 유지되고, 확인 삭제가 총점을 0점으로 되돌리는 것을 확인했다. 합성 장면의 마커는 테스트 카메라의 촬영 범위 안에 들어오도록 위치를 이동했다.
