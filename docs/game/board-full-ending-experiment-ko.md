# 6×6 보드 가득 참 종료 규칙 실험 (실험용, 출하 8×8 무변경)

스크립트: `scripts/board-full-ending-experiment.ts` (미추적 새 파일)
원시 로그와 요약: `D:\DevCaches\tmp\qroker-board-full\raw\` (저장소 밖)

## 세 질문에 대한 답

1. **6×6이 이제 올바르게 끝나는가? 예.** 6×6 짝 실험 600게임 전부 `ENDED`로 끝났고 드라이버 오류는 0건이다. 모든 보드 가득 참 게임은 배치 32번째에 끝났다. 33번째 배치를 요청한 적은 없다. 최종 점수 검사(배치 전 점수 + 이 배치의 획득 점수 + 보너스 1회)와 종료 후 거부 검사는 447개 보드 가득 참 게임에서 모두 통과했다. 범주별 검사(1,800게임 탐색)도 실패 0건이다.
2. **넷째 차례에 측정 가능한 이점이 있는가? 아니다.** 넷째 좌석의 전체 승자 점유율은 판에 따라 18.8%에서 30.5%까지 흩어진다. 6×6 BEGINNER에서는 1번째 좌석 31.8%(구간 24.8–38.8), 4번째 좌석 18.8%(구간 13.8–24.3)로 단독 구간이 25%를 벗어난다. 같은 시드의 8×8과 비교한 짝 차이는 모든 좌석에서 구간이 0을 포함한다(6×6 BEGINNER 1번째 +4.8, 4번째 −5.3). 여러 판을 비교했으므로 이 단독 구간은 확정 근거로 쓰지 않는다. 마지막 배치 효과는 아래 결과 3에서 따로 본다. 마지막 배치가 선두 집합을 바꾼 경우는 447게임 중 16건(3.6%)이었다. 넷째 좌석이 단독 또는 공동 선두를 얻은 경우는 4건, 잃은 경우는 2건이다.
3. **사람 플레이테스트를 정당화할 만큼 점수 결정이 생기는가? 부분적으로 그렇다.** 코드 수는 ADVANCED 위주 판에서 8×8과 비슷하다(OWNER ADVANCED 4.96 대 4.98, OWNER MIXED 3.51 대 3.89). BEGINNER와 BLIND ADVANCED 판은 게임당 코드가 1.3–1.6개로 적고, 게임의 16–30%는 코드가 한 번도 없다. 그래서 짧은 플레이테스트에는 충분하지만, 점수 결정이 풍부하다고 할 수는 없다.

**추천:** 6×6을 이 규칙을 적용한 실험 빌드로 제한된 사람 플레이테스트에 올린다. 8×8 출하본은 그대로 둔다. 사람 선호와 플레이 시간은 측정하지 않았다.

## 구현

- 6×6 복사본(`D:\DevCaches\tmp\qroker-board-full\v6new`)에서만 수정했다. 출하 `src/game`은 수정하지 않았다.
- `core/engine.ts`: 배치 후 `boardFull = board.every(cell !== null)`을 계산한다. 코드가 있으면 `endsGame`에 `|| boardFull`을 더한다. 코드가 없으면 기존 손패 소진 처리 다음, 덱 소진 검사 앞에서 `ENDED`로 간다. 보너스는 기존 경로에서만 주고, 보드 가득 참 자체는 보너스가 없다.
- `sim/play-game.ts`: 불변식 `PENDING_BATCH`와 `PHASE_SHAPE`가 보드 가득 참을 허용하도록 한 줄씩 고쳤다. 칸 수 점검은 36칸으로 바꿨다.
- 드라이버는 `playGame`을 쓰지 않고 같은 루프를 직접 돌린다. 보드가 가득 찼는데 배치를 요청하면 오류로 기록한다. 8×8 복사본에서 `playGame`과 12/12 게임의 행동 로그와 점수가 같았다.

## 종료 기록 (게임마다 플래그를 따로 기록)

`boardFull`, `codeLimit`(코드 5개 도달), `bonusSeat`(손패 소진 보너스), `deckEmpty`를 모두 기록한다. 주된 종료 사유는 한 번만 센다. 우선순위는 손패 소진 > 코드 한도 > 보드 가득 참 > 덱 소진이다. 본 실험(600게임)에서는 보드 가득 참과 다른 종료 조건이 겹친 경우가 0건이었다. 1,800게임 탐색에서는 겹침이 6건(코드 한도 2, 손패 소진 4)이었다.

## 검증과 한계

- 시드 1–100, 회전 r = (시드 − 1) mod 4. 회전마다 25 시드씩 쓴다. 혼합 등급은 4번 회전에서 각 턴 좌석에 ADVANCED가 두 번씩 온다.
- 실패 0건: 600 짝 시드(8×8 600게임과 6×6 600게임), 1,800 탐색 게임, 시드 5 회귀, 스모크 24게임.
- 신뢰구간은 시드를 재표집한 부트스트랩(2,000회, 고정 난수)이다.
- AI(BEGINNER, ADVANCED)는 사람이 아니다. 사람이 이 규칙을 어떻게 받아들이는지, 플레이 시간은 측정하지 않았다.
- 손패 소진 보너스(5점)는 출하 설정값이다. 이 실험에서 바꾸지 않았다.
