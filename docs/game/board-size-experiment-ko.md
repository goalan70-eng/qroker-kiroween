# 보드 크기 실험: 8×8 사용량과 6×6 실제 플레이 (AI 자가 대국)

실험 스크립트: `scripts/board-size-experiment.ts` (실험 전용, 출하 코드 변경 없음)
원시 로그와 요약: `D:\DevCaches\tmp\qroker-board-size\raw\` (저장소 밖, 저장하지 않음)

## 방법

- 기준선: 현재 저장소의 8×8 엔진(`src/game`)을 그대로 실행.
- 6×6 변형: `D:\DevCaches\tmp\qroker-board-size\v6\src\game` 복사본에서 다음 네 곳만 바꿨다.
  1. `core/geometry.ts`: `BOARD_SIZE` 8→6, 열 문자 `ABCDEF`, 표기 패턴 `/^[A-F][1-6]$/`.
  2. `core/board.ts`: 시작 칸을 C3, D3, C4, D4로 옮김. D4, E4, D5, E5와 같은 순서(TL, TR, BL, BR)와 방향 0.
  3. `sim/play-game.ts`: 불변식 `BOARD_CELLS` 64→36 (칸 수 점검만 바뀜).
- 짝짓기: 같은 시드 1–100에서 덱 순서, 초기 손패, 시작 좌석(P0), 공개 방식, AI 등급 배치가 두 보드에서 같다.
- 공개 방식: `OWNER_ONLY`, `BLIND`. 등급 배치: 전원 BEGINNER, 전원 ADVANCED, 혼합(짝수 시드는 P0·P2 ADVANCED, 홀수 시드는 P0·P2 BEGINNER).
- 포화 처리: 빈 칸이 없어 배치가 필요한 턴은 `SATURATED`로 기록한다. 규칙을 새로 만들지 않고 게임을 멈춘다. 모든 분모에 포함.
- 검증(smoke): 8×8 복사본은 시드 1, 2 × 공개 2 × 등급 3 = 12 게임에서 `playGame`과 행동 로그, 점수가 모두 같았다(12/12). 6×6은 A1–F6만 받고, G1, A7은 거부, 36개 칸이 서로 다르다.

## 결과 2: 8×8 판이 6×6 안에 들어가는가

8×8 정상 종료 600게임의 최종 점유 칸 범위(시작 카드 포함)를 측정했다.

| 조건 | 비율 |
|---|---|
| 행 범위가 6행을 넘음 | 67.0% |
| 열 범위가 6열을 넘음 | 75.8% |
| 행 또는 열 중 하나라도 6을 넘음 | 85.2% |

즉 8×8 게임의 85%는 6×6 판에 맞지 않는 범위로 퍼진다. 반대로 바깥 고리에 한 번 닿는 것과는 다르다. 설정별로 보면 BLIND 전 등급 98–100%, OWNER_ONLY BEGINNER 100%, OWNER_ONLY ADVANCED 30%다.

## 결과 3: 6×6 실제 게임

분모는 모든 칸 100게임. `포화`는 보드 포화로 다음 배치가 불가능해진 게임이다. 포화는 항상 P0의 턴이었다(배치 32개 후 33번째 배치).

| 공개 | 등급 | 보드 | 정상 종료 | 포화 | 평균 배치 | 평균 코드 | 종료 사유 (덱 소진 / 코드 한도 / 손패 소진) |
|---|---|---|---|---|---|---|---|
| OWNER_ONLY | BEGINNER | 8×8 | 100 | 0 | 37.23 | 1.30 | 97 / 1 / 2 |
| OWNER_ONLY | BEGINNER | 6×6 | 0 | 100 | 32.00 | 1.34 | – |
| OWNER_ONLY | ADVANCED | 8×8 | 100 | 0 | 12.71 | 4.98 | 0 / 90 / 10 |
| OWNER_ONLY | ADVANCED | 6×6 | 97 | 3 | 13.93 | 4.96 | 0 / 86 / 11 |
| OWNER_ONLY | MIXED | 8×8 | 100 | 0 | 27.43 | 3.66 | 30 / 9 / 61 |
| OWNER_ONLY | MIXED | 6×6 | 55 | 45 | 26.31 | 3.55 | 0 / 8 / 47 |
| BLIND | BEGINNER | 8×8 | 100 | 0 | 37.23 | 1.30 | 97 / 1 / 2 |
| BLIND | BEGINNER | 6×6 | 0 | 100 | 32.00 | 1.34 | – |
| BLIND | ADVANCED | 8×8 | 100 | 0 | 37.17 | 1.29 | 97 / 0 / 3 |
| BLIND | ADVANCED | 6×6 | 3 | 97 | 31.64 | 1.42 | 0 / 0 / 3 |
| BLIND | MIXED | 8×8 | 100 | 0 | 36.58 | 1.71 | 88 / 2 / 10 |
| BLIND | MIXED | 6×6 | 12 | 88 | 31.04 | 1.76 | 0 / 1 / 11 |

포화 게임의 덱 잔량은 4–8장이다. 이는 기존 규칙(코드를 완성한 배치는 카드를 보충하지 않음)과 맞는다. 예: 배치 32개, 코드 4개면 36 − (32 − 4) = 8장.

**포화된 6×6 예시:** 시드 5, OWNER_ONLY, MIXED. 배치 32개, 코드 4개, P0 턴, 덱 8장. 시작 칸은 S, 점유 칸은 #.

```

 #  #  S  S  #  #
 #  #  S  S  #  #
 #  #  #  #  #  #
 #  #  #  #  #  #
```

## 결론

**추천: 8×8 유지. 6×6은 현재 상태로 사람 플레이테스트에 올리지 않는다. 먼저 빈 판에서 배치가 불가능할 때의 처리 규칙을 소유자가 정해야 한다.**

근거가 된 측정값은 두 가지다.
1. 6×6에서 BEGINNER 전 설정(100%)과 BLIND ADVANCED(97%), BLIND MIXED(88%), OWNER_ONLY MIXED(45%)가 포화된다. 36칸에서 시작 카드 4장을 빼면 배치 32개로 판이 꽉 차기 때문이다. 기존 규칙에는 이 경우의 처리가 없다. 그래서 규칙을 만들지 않고 기록만 했다.
2. 8×8 게임의 85.2%가 6×6 범위를 넘는다. 바깥 고리 사용도 93%다. 그래서 8×8을 줄이면 게임 구조가 바뀐다.

**AI 공간 사용과 사람 선호는 다르다.** 이 결과는 BEGINNER와 ADVANCED AI가 어떻게 두는지를 보여 준다. 사람이 어떤 판을 좋아하는지는 측정하지 않았다. BLIND ADVANCED는 코드가 평균 1.29개뿐이다. AI가 보이는 정보로만 판단하는 것이 원인일 가능성이 있지만, 전략 코드는 검증하지 않았다.

## 검증과 한계

- 8×8 smoke 12/12 일치. 6×6 표기 검사 통과(36칸, G1 거부, A7 거부).
- 오류 게임 0건 (1,200게임).
- 시작 좌석은 P0 고정. 등급 혼합은 시드 홀짝으로 번갈아 바꿨다.
- 6×6 포화는 모든 설정에서 배치 32개 뒤 P0 턴에 일어난다. 이는 구조적 결과이지 AI 선택이 원인이 아니다.
- 실험 결과는 합성 AI(BEGINNER, ADVANCED) 기준이다. 사람 행동이나 실제 플레이 시간과 무관하다.
