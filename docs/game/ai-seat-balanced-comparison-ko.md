# ADVANCED 대 BEGINNER: 좌석 균형 비교

**합성 헤드리스 자체 대국(synthetic self-play)의 결과다.** 사람 플레이 결과가 아니며, 임시 점수표(`DEV_PLACEHOLDER`, provisional)에서 나온 값이다. 점수 균형이나 확정 난이도를 주장하지 않는다. 이전 보고서 `docs/game/headless-diagnostics.md`는 바꾸지 않았다.

## 질문과 방법

현재 점수 규칙에서 두 등급이 모든 좌석을 똑같이 맡을 때 ADVANCED가 BEGINNER보다 높은 성과를 내는가.

- 시드 0~199마다 같은 초기 패 배분, 같은 시작 좌석(P0)으로 두 판을 둔다. 1판: ADVANCED가 P0/P2, BEGINNER가 P1/P3. 2판: 등급을 맞바꾼다.
- `OWNER_ONLY`와 `FACE_UP`을 각각 실행하고 따로 보고한다. 총 800판(200시드 × 2배정 × 2모드).
- 기존 엔진(`playGame`, 불변식 검사 켜짐), 전략(`getStrategy`), 순위(`rankPlayers`), 시드 처리를 그대로 썼다. 게임 규칙, AI 전략, 점수 값은 바꾸지 않았다.
- **실제 사용한 점수 설정**(런타임 `defaultConfig()`에서 읽음): `rewardByError = [10, 5, 4, 3, 2, 1]`(오차 6 이상은 0점), `handEmptyBonus = 5`. 이전 진단 보고서의 본문에는 `[6, 4, 3, 2, 1]`과 보너스 3이 적혀 있어 현재 값과 다르다. 이전 보고서는 그대로 보존했다.

재실행 명령(약 10초):

```powershell
npx --no-install tsx scripts/ai-seat-balanced-comparison.ts --out test-results/ai-seat-balanced-comparison.json
```

스모크 점검은 `--seeds 2`를 붙인다. 분석 스크립트는 `scripts/ai-seat-balanced-comparison.ts`이고 JSON을 stdout에 낸다. 모든 판이 완료되고 점검이 통과할 때만 종료 코드 0이다.

## 집계 기준

- **순위**: `rankPlayers`의 경쟁 순위(점수가 더 높은 좌석 수 + 1). 동점은 같은 순위를 받는다. 평균 순위는 등급별 좌석-판(판마다 등급당 2좌석)의 평균이다.
- **단독 1위**: 1위가 한 좌석뿐인 판의 그 좌석. **공동 1위**: 1위를 둘 이상이 나눈 판에서 1위인 좌석-판 하나하나(공동 1위 판 21개 → 좌석-판 42개).
- **추측 집계**: 판마다 Composite Code 하나, 좌석 하나가 추측 1건이다. 한 번에 코드 두 개가 완성되면 코드마다 따로 센다. 오차는 `|추측 − 정답 합|`이다. 두 등급이 같은 수의 추측을 한다(좌석 수가 같다).
- **손패 소진 보너스 빈도**: 보너스를 받은 좌석이 속한 등급의 판 수(판당 한 좌석, 400판 중).
- **점수 차이**: 시드마다 (ADVANCED 좌석 평균 점수 − BEGINNER 좌석 평균 점수)를 두 배정에서 구해 평균한 값이다. 표의 표준오차는 이 200개 시드 평균의 설명용 값이며 검정이 아니다.

## 스모크 점검 (시드 0~1)

실행 8판 모두 완료(종료 코드 0). 모드마다 짝 2쌍의 초기 패 배분이 같았다(보드, 덱, 손패, 시작 좌석 비교). 첫 좌석은 두 등급이 2판씩 가졌고, 모든 판이 `ENDED`와 4좌석 순위를 만들었다.

## 결론

- 두 모드 모두에서 좌석을 균등하게 맡겨도 ADVANCED가 BEGINNER보다 크게 앞섰다. OWNER_ONLY에서는 200개 시드 중 199개에서 ADVANCED가 앞섰고 동점 1개, BEGINNER 우세 시드는 없다. FACE_UP에서는 200개 시드 모두 ADVANCED가 앞섰다.
- 등급을 맞바꾸자 OWNER_ONLY의 점수 차이가 13.0175에서 11.5675로 1.45점 줄었다. P0/P2와 P1/P3의 등급을 동시에 바꿨으므로 이 비교만으로 P0의 선공 효과를 따로 추정할 수 없다. FACE_UP에서는 두 배정의 점수 차가 각각 49.025와 49.0175였다.
- OWNER_ONLY에서 평균 추측 오차는 ADVANCED 3.93, BEGINNER 13.29였다. 좌석당 평균 점수 격차 12.2925점 중 예측 점수 차이가 9.855점(약 80%)을 차지했다. 손패 소진 보너스는 400판 중 ADVANCED가 395판, BEGINNER가 5판에서 받았고, 좌석당 평균 격차에 2.4375점을 더했다.
- FACE_UP에서 ADVANCED는 모든 카드 정체가 보이므로 정답 합을 그대로 추측한다(`src/game/ai/heuristic.ts`의 설계 설명과 일치). 오차 0, 정확도 100%이고 BEGINNER는 신원을 읽지 않아 오차가 두 모드에서 비슷하다(13.3). 따라서 FACE_UP의 격차는 전략 격차보다 정보 노출 규칙의 효과가 크다.
- 보류 없이 모든 판이 완료됐다. 미완료 판은 없다.

## 아직 알 수 없는 것

- 사람 플레이어에게 어느 등급이 어렵거나 쉬운지는 알 수 없다. 두 등급 모두 단순 휴리스틱 전략이며 사람의 추측 정확도, 학습, 실수를 반영하지 않는다.
- 점수표는 임시값이다. 다른 표에서는 점수와 격차가 달라진다. 점수 균형이나 확정 난이도를 이 결과로 주장하지 않는다.
- 시드는 0~199뿐이다. 표준오차는 설명용이고 통계 검정은 하지 않았다.
- 사람 동석 게임에서 `OWNER_ONLY`가 어떻게 체감될지, 실제 손패 정보가 얼마나 추측에 도움이 되는지는 측정하지 않았다.
