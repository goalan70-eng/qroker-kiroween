# Kiro usage and evidence

English submission evidence note, prepared 2026-11-16. **Owner review required before publication.** This document separates inspected repository artifacts from the owner's historical account; it does not independently certify which assistant generated every commit.

## Proposed short submission account

> The project owner reports using Kiro as the primary specification-driven tool for QRoker's requirements, design, task planning and initial implementation. The public repository preserves two requirements-first spec families and hook configurations under root `.kiro`. A later Codex audit inspected these artifacts and performed separately attributed acceptance-test, score-table, optical-repair and submission-preparation work. Original Kiro session transcripts were not audited. We do not claim all code was generated by Kiro or infer feature execution from configuration files.

Before publishing, the owner must confirm the actual Kiro platform(s), relevant sessions and that this account accurately describes their meaningful use. No platform or session identifier has been filled in by inference.
