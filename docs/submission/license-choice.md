# Project license — owner decision pending

**Proposal only. No project license is granted by this draft.** There is no root
`LICENSE` yet, and the project must not be described as open source until the
owner approves a license and its complete text is added to the public revision.

[Issue #5](https://github.com/goalan70-eng/qroker-kiroween/issues/5) explicitly
requires a user-approved license and prohibits choosing one arbitrarily. The
owner has been asked to select the license and copyright attribution; no answer
has been assumed. Third-party terms remain in [the notices](../../THIRD_PARTY_NOTICES.md).
