# QRoker Offline 0.2.14 실물 카드 시험

기종 ______ · Android 버전 ______ · 시험일 ______ · 조명 ______ · 시작 회차 ______ · 시작 총점 ______

[설치 파일 선택 안내](../../prototypes/android-offline-companion/README.md)에 따라 APK를 고른다. 기존 기록이 있으면 아래 두 조합을 아직 채점하지 않은 시험 기기나 별도 Android 사용자 프로필을 사용한다.

[1.5 mm 양면 카드 PDF](../../prototypes/screen-playtest/deliverables/black-white-registered-15mm/QRoker-1.5mm-duplex-A4.pdf)에서 앞면 시험에 필요한 페이지만 실제 크기(100%)로 출력한다. 5♥·9♥는 1쪽, 5♦는 3쪽, 9♦는 5쪽, J♣·2♠는 9쪽이다. 모서리를 재단하고 네 장 아래 중앙에 [도안 ZIP](../../prototypes/screen-playtest/deliverables/black-white-registered-15mm/QRoker-1.5mm-duplex-SVG.zip)의 받침(`support.png`)을 가로 15 mm로 출력해 둔다. 모자 무늬가 완성되도록 [A 배치 예시](../../prototypes/screen-playtest/evidence/kiro-registered-15mm-release-retest-20261125-2026/0-250-0.png)와 방향을 맞춘다.

| 앞면 배치 | 윗줄 (왼쪽 → 오른쪽) | 아랫줄 (왼쪽 → 오른쪽) | 정답 합 |
|---|---|---|---:|
| A | 5♥, 9♦ | J♣, 2♠ | 27 |
| C | 9♥, 5♦ | J♣, 2♠ | 27 |

각 시도는 점수판의 **Scan code / 코드 인식**에서 시작한다. 1번부터 순서대로 실행하고 전후 회차·총점을 기록한다.

| 순서 | 휴대전화에서 할 일 | 기대 결과 | 관찰 결과 |
|---|---|---|---|
| 1 | A를 비춰 입력창을 열고, 확정 전에 카드 한 장을 뺀다. | 입력창이 닫히고 회차·총점이 유지된다. | 미시험 |
| 2 | A를 복원한 뒤 27을 입력하고 같은 조합을 계속 비추며 확정한다. | 정답 27, 새 회차 1개, 총점 +10. | 미시험 |
| 3 | 윗줄을 C로 교체한 뒤 다시 스캔하고 27을 확정한다. | 새 회차가 한 개 더 생긴다. 정답 27, 시작 대비 총점 +20. | 미시험 |
| 4 | A를 다시 스캔한다. | 이미 기록한 조합이라는 안내가 뜨고 회차·총점이 유지된다. | 미시험 |
| 5 | 앱을 완전히 종료하고 다시 연다. 두 회차를 열어 본 뒤 C를 재스캔한다. | 두 회차의 예측·정답이 각각 27이고 누계가 유지된다. C도 중복 안내가 뜬다. | 미시험 |

새 조합에서 중복 안내가 뜨면 조합과 화면을 함께 촬영한다. 입력창이 열리지 않으면 중복 안내가 있었는지 먼저 적고, 거리·그림자·초점 중 하나만 바꿔 다시 시도한다. 잘못된 합이나 이중 채점이 나오면 그때의 배치와 회차 기록을 보존한다.
