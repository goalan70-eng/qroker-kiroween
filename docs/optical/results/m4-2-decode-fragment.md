# Fragment decoder: exact enumeration (task 4.2)

**Synthetic model, not real cameras.** This is an EXACT enumeration of the independent-uniform-bit-flip
model, not a sample, so there is no sampling error and no confidence bound is needed. It is not a model of real
image corruption (blur, misaligned sampling and lighting do not flip independent bits).

Model: a template T (52 cards x 8 D4 transforms = 416) is corrupted by exactly k independent,
uniformly chosen bit flips; every one of the C(25,k) masks is equally likely. Each (T, mask) pair is visited once,
so the number of events at weight k is 416 x C(25,k). The decoder accepts a word iff exactly one DISTINCT card has a
template within the radius. correct = accepted as the source card (any transform); exact transform = the source
template is the nearest template of that card; falseAccept = accepted as a different card; rejected = the rest
(CORRUPTED_FRAGMENT or AMBIGUOUS).

Codebook SHA-256: 515ECEB318648C14A47574496788236A2B1BBDFC7062387DB09303CB717CC2D4 (matches the frozen hash)
